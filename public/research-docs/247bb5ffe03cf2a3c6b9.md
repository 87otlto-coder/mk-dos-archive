# Project: MK DOS Archive

## Purpose
Personal-use research and asset reconstruction tool for the DOS PC versions of Mortal Kombat, Mortal Kombat II, and Mortal Kombat 3.

## Primary Objectives
- Directory-based game discovery
- Executable and resource analysis
- Raw asset inventory
- Provenance tracking across all layers
- Recovered relationships
- Fighter reconstruction
- Arena reconstruction
- Asset export

## Non-Goals For Now
- Arcade ROMs
- Console ports
- Windows versions
- Ultimate Mortal Kombat 3 / Mortal Kombat Trilogy
- Localization support
- Modding / repacking
- Game execution / full x86 emulation

## Core Principle
- Research before reconstruction.
- Reconstruction before polish.

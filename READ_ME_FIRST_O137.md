# MK DOS Archive — O137 original stage animation research

The latest development source adds **43 original, source-ordered stage effect sprite frames** for Tomb (16), Portal (20), Tower (7). They are exported uncropped, preserving original indexed source pixels and separate transparency masks. The Tomb/Portal stage viewer also previews source-ordered effects.

Read `CHECKPOINT_2026-10-12_O137_TOWER_AND_ORIGINAL_ANIMATIONS.md` and `MK_DOS_Archive_MASTER_HANDOFF_2026-10-12_THROUGH_O137_ORIGINAL_ANIMATION_FRAMES.md` for exact source addresses, reproducibility and limitations. The normal development ZIP contains software and research evidence, not original commercial MK2.EXE/GRA assets. Use your own authentic game files for extraction.

**Proven:** source frame order, sprite byte boundaries, palette indices, alpha masks and pointer-list provenance. **Not proven:** original playback FPS, triggers, per-frame seconds, exact layer placement, parallax, Tower's live palette ownership, or the complete React application build.

# MK DOS Archive — O269 evidence-first MK1/MK2 mechanism registry

Date: 2026-10-18. Inherit `MK_DOS_Archive_Source_O268_Pit_II_2026-10-18.zip` unchanged.

## Why this pass exists

Pit II O267/O268 authenticated part of the MK2 palette-to-display pipeline. The longer MK1 history already contains bounded source-preserving sprite, palette, animation, and background editors. Those findings can accelerate subsequent research if recoverable as typed, source-linked mechanisms **without collapsing MK1 and MK2 into a guessed common binary format**.

O269 is the first additive **read-only research infrastructure** pass. It does not change application UI, game binaries, existing extractors, existing serializers, or editor permissions. It does not declare any new MK-DOS family-wide encoding rule.

## Added

- `research_outputs/O269_MK_DOS_MECHANISM_REGISTRY.json`: 11 game-scoped mechanism records (MK1 5; MK2 6), two explicitly constrained cross-game candidates, unresolved research boundaries, canonical EXE fixture SHA-256s, and typed address spaces.
- `src/core/research/mechanismEvidenceRegistry.ts`: typed fail-closed registry validation, scoped search, and evidence lookup usable by the existing app in a future UI pass.
- `scripts/verify-o269-mechanism-registry.mjs`: checks existing linked evidence paths, rejects 12 corruption controls, validates canonical MK2 SHA-256, and checks three original MK2 source anchors.
- `scripts/query-o269-mechanisms.mjs`: read-only query CLI for game/category/mechanism ID, with optional JSON output.

## Crucial scope restrictions

- A shared evidence/provenance schema is **not** a shared MK1/MK2 runtime ABI or graphics decoder.
- The MK2 indexed sprite research explicitly calls the command-form similarity with MK1 an observation **without cross-game promotion**. O269 preserves this boundary.
- `LIVE_DEBUGGER_WITNESSED` distinguishes O260/O267 actual paused CPU/memory observations from source-only O268 VRAM-write analysis.
- Code physical offsets, runtime code EIPs, writable data globals, and loaded palette source pointers are independent coordinate domains. There is no universal addition constant across them.
- Registry records are **read-only knowledge**, not compile permissions. MK1 Rayden X/Y edits remain bounded to the specific 13 qualified descriptors.
- O248 texture-hold timing, exact framebuffer changes, and displayed frame cadence **remain unresolved**. The Portal-derived ~50 fps video baseline is not automatically the task tick rate.
- No MK3 mechanism has been promoted or inherited without independent proof.

## Usage

```sh
node --experimental-strip-types scripts/query-o269-mechanisms.mjs --game mk1 --category authoring
node --experimental-strip-types scripts/query-o269-mechanisms.mjs --game mk2 --category runtime
node --experimental-strip-types scripts/query-o269-mechanisms.mjs --id mk2.palette_dac --json
node --experimental-strip-types scripts/verify-o269-mechanism-registry.mjs --mk2-exe /path/to/ORIGINAL_MK2.EXE --output /tmp/O269.json
tsc --noEmit --target ES2022 --module ESNext --moduleResolution Bundler --skipLibCheck src/core/research/mechanismEvidenceRegistry.ts
```
